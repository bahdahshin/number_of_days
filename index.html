01 / Under the hood

Small workflow. Complete loop.

Select a step to explore how a scheduled event becomes a recorded change.

add_day.yml / trigger
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

The schedule requests a run at midnight UTC. Manual dispatch makes it possible to run the same workflow on demand. Scheduled runs can be delayed by GitHub, so the total represents increments, not an exact measure of elapsed days.

02 / Engineering choices

Make the work visible.

[↻]

Automate the repeatable.

A recurring task belongs in a workflow. The project connects a scheduled trigger to a concrete state change without a dedicated server.

[+]

Keep the system legible.

The counter is plain text and the operation is shell arithmetic. A reviewer can follow the entire automation in a single workflow file.

[→]

Show the evidence.

The source, workflow runs, and commit history are open for inspection. The implementation is small enough to read and the results are recorded.
